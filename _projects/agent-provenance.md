**Status:** exploratory, ongoing (2026–present)

### Idea

When an agent takes an action, it is often hard to say _why_. Which user instruction, tool output, or retrieved document led it to call a particular tool with particular parameters? Provenance, the record of where information came from and how it flowed, is a well-studied idea in databases, security, and programming languages. I am exploring how provenance can help explain and check agent behavior, especially when untrusted information influences an agent's actions.

### Focus areas

- Provenance tracking across agent–tool interactions
- Parameter-level and tool-level behavior
- Detecting when untrusted inputs influence sensitive actions
- Agent safety
- Evaluation on existing agent-safety benchmarks

_This is early-stage work. Any benchmark numbers that appear here will be clearly labeled as either results reported in the literature or my own experimental results._
