**Role:** Full-stack developer · **When:** Dec 2024–Mar 2025

**Tech:** Node.js (VS Code Extension API), Flutter, Dart

### What it does

An open-source VS Code extension that scaffolds a full Clean Architecture feature for a Flutter app with a single command.

- Generates the BLoC, use case, and repository layers automatically, reducing boilerplate setup by about 80%.
- Detects the existing project structure and repairs inconsistencies, so teams keep a consistent modular architecture.
- 190+ installs.

### Why it is here

Enforcing an architecture automatically means encoding its rules (which layer may depend on which, where each component belongs) as something a tool can check and repair. That same idea, making implicit structural contracts explicit and checkable, runs through my research interests.
